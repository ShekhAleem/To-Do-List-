# 📝 To-Do List App

A simple and responsive To-Do List App built using **HTML, CSS, and JavaScript**.

## 🚀 Features

- ➕ Add new tasks
- 📅 Select a date for each task
- ✏️ Edit tasks using a pencil icon
- ✅ Mark tasks as completed
- ❌ Delete tasks
- 💾 Save tasks using Local Storage
- 📱 Simple and user-friendly interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage

⚙️ How It Works
1.Enter a task in the input box.
2.Select a date using the calendar icon.
3.Click Add to add the task.
4.Click the checkbox to mark the task as completed.
5.Click ✏️ to edit the task and date.
6.Click × to delete the task.
7.Tasks are stored using browser Local Storage.
